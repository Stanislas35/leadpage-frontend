Mesurer une campagne : ce qui est fiable, ce qui ne l'est pas

Les antivirus et les aperçus de messagerie ouvrent les liens avant le destinataire. Voici comment lire vos chiffres sans vous raconter d'histoires.

En bref
  • L'ouverture et le clic seuls sont peu fiables.
  • Le temps actif et les pages atteintes sont de meilleurs signaux.
  • Le clic sur le lien de rendez-vous est le plus solide.

Pourquoi le clic seul ne prouve rien

Beaucoup d'entreprises protègent leurs boîtes avec des scanners de sécurité. À la réception du mail, ces outils suivent les liens pour vérifier qu'ils sont sûrs. Votre outil d'envoi enregistre un clic, alors que personne n'a rien lu.

Les aperçus de messagerie et les pixels d'ouverture posent un problème voisin : l'ouverture peut être préchargée, ou au contraire bloquée. Le taux d'ouverture est devenu un indicateur peu fiable.

Ce que mesure LeadPage

Le document s'affiche dans une page de lecture. Une lecture n'est confirmée qu'après quelques secondes de présence active, onglet visible. Le temps est cumulé, la page la plus avancée est conservée, et le clic sur votre lien de rendez-vous est enregistré.

Les ouvertures par des robots connus (scanners de sécurité, aperçus automatiques) sont enregistrées à part et n'entrent pas dans les taux.

Les limites, honnêtement

Limites
  • Aucun système n'exclut tous les robots.
  • La mesure ne dit rien de l'ouverture du mail lui-même.
  • Elle ne s'applique qu'aux liens générés avec LeadPage.

Servez-vous de ces chiffres pour classer vos relances et comparer deux vagues entre elles, pas pour mesurer au point près.

Un tableau de relance simple

  • Priorité 1 : lien de rendez-vous cliqué. Appelez ou répondez vite.
  • Priorité 2 : lecture longue, pages avancées. Relancez avec une question sur le sujet lu.
  • Priorité 3 : ouverture sans lecture. Une relance courte, avec un angle différent.
  • Priorité 4 : aucune ouverture. Attendez, ou changez de canal.
